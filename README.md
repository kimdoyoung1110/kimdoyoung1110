## 🙋‍♂️ About Me

- 🏢 **[Slunch Factory](https://slunch.co.kr/)** 에서 **프론트엔드 인턴** — VeggieVerse 서비스/관리자 웹을 개발하고 있어요.
- 🧑‍💻 인천대 **[앱센터](https://github.com/inu-appcenter)** 소속 — **[memorIN](https://github.com/inu-appcenter/memorIN)** 프로젝트의 **백엔드 시니어**로 Spring Boot · PostgreSQL · 실시간 채팅(WebSocket) 서버를 설계하고 있습니다.
- 🛒 **[CartrAIder](https://github.com/CartrAIder)** 팀에서 스마트 AI 카트 고객용 모바일 앱(React Native · Expo)을 만들고 있어요.
- 🤖 앱센터 **통합 AI 서버(AI Chatbot)** 백엔드를 개발하며 **RAG 기반 LLM** 파이프라인을 구축하고 있습니다.
- 🔬 인천대 **인공지능빅데이터센터** 학생연구원으로 RAG · LLM Agent를 연구하고 있어요.
- 🚀 개발자 커뮤니티 **[Techeer](https://www.techeer.net/)** 활동 중 · 3D 데이터 시각화와 웹 성능 최적화에 강점이 있습니다.
